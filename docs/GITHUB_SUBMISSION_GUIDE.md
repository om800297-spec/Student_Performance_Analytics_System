# GitHub and Submission Guide

## A. Create a GitHub repository
1. Sign in to GitHub or create an account.
2. Select **New repository**.
3. Repository name: `Student-Performance-Analytics-System`.
4. Add a short description: `Python student marks analytics using Pandas and NumPy`.
5. Choose Public if your teacher requires a public link; otherwise follow the teacher's instructions.
6. Do not add another README if you are uploading this project's existing files.
7. Create the repository.

## B. Upload using the website (simplest)
1. Open the new, empty repository.
2. Select **Add file → Upload files**.
3. Extract the project ZIP on your computer first.
4. Upload `main.py`, `requirements.txt`, `README.md`, `.gitignore`, and the `data` and `docs` contents.
5. Do not upload `.venv`, private student records, or generated output files.
6. Enter commit message: `Add Student Performance Analytics System`.
7. Select **Commit changes**.
8. Copy the repository page link for your submission.

## C. Alternative: upload using VS Code Source Control
1. Install Git and open the extracted project folder in VS Code.
2. Open Source Control from the left sidebar.
3. If prompted, select **Initialize Repository**.
4. Stage the project files using the `+` beside Changes, or stage all changes.
5. Enter commit message `Add Student Performance Analytics System` and select **Commit**.
6. Select **Publish Branch** or add your GitHub remote and push, then sign in when prompted.
7. Confirm the files are visible in the GitHub repository.

## D. Verify before submission
- [ ] `python main.py` runs successfully.
- [ ] `README.md` explains installation and use.
- [ ] `docs/PROJECT_DOCUMENTATION.md` is included.
- [ ] `data/students.csv` is included and uses fictional sample data.
- [ ] GitHub repository opens in a browser.
- [ ] Paste the repository link into the teacher's Google Form.
- [ ] If the teacher requests a ZIP, submit the ZIP as well.
